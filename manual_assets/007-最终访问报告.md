### 3.2 后端服务状态

**问题症状**:
- 所有API接口请求超时（>10秒）
- 登录API无响应
- 部分静态资源（CSS/JS）超时

**测试命令及结果**:
```bash

```

**浏览器Console错误**:
```
❌ GET element-plus CSS - net::ERR_CONNECTION_TIMED_OUT  
❌ GET index CSS - net::ERR_CONNECTION_TIMED_OUT  
❌ POST /webuser/api/login - Network Error
❌ GET adminlogin/api/utils/qrcode/qet.i - net::ERR_CONNECTION_TIMED_OUT
```

**可能的技术原因**:
1. **应用服务器未启动**: Nginx提供静态文件，但后端Java/Python/Node.js服务未运行
2. **数据库连接故障**: 后端服务启动但无法连接数据库，请求hang住
3. **反向代理配置错误**: API路径代理到错误的后端地址或端口
4. **防火墙内部规则**: 对外端口8091开放，但内部服务间通信被阻断
5. **资源耗尽**: 内存/连接池耗尽，无法处理新请求

## 六、给系统管理员的建议

### 6.1 立即检查项

1. **后端应用服务状态**:
   ```bash
   # 检查Java进程（示例）
   ps aux | grep java
   ps aux | grep tomcat
   
   # 检查Node.js进程（示例）
   ps aux | grep node
   
   # 检查Python进程（示例）
   ps aux | grep python
   ps aux | grep gunicorn
   ```

2. **端口监听状态**:
   ```bash
   # 检查8091端口的完整监听情况
   netstat -tlnp | grep 8091
   lsof -i :8091
   
   # 检查后端应用端口（如8080、3000等）
   netstat -tlnp | grep -E "8080|3000|8081"
   ```

3. **数据库连接**:
   ```bash
   # MySQL
   systemctl status mysql
   mysqladmin -u root -p ping
   
   # PostgreSQL
   systemctl status postgresql
   pg_isready
   
   # MongoDB
   systemctl status mongod
   mongosh --eval "db.adminCommand('ping')"
   ```

4. **Web服务器配置**:
   ```bash
   # Nginx
   nginx -t  # 测试配置文件
   tail -f /var/log/nginx/error.log
   
   # 检查反向代理配置
   cat /etc/nginx/sites-enabled/default | grep proxy_pass
   ```

5. **应用日志**:
   ```bash
   # 查看最近的应用错误
   tail -100 /var/log/your-app/error.log
   journalctl -u your-app-service -n 100
   ```

### 6.2 常见解决方案

**场景1: 后端服务未启动**
```bash
systemctl start your-backend-service
systemctl enable your-backend-service  # 设置开机自启
```

**场景2: 数据库连接失败**
- 检查数据库服务是否运行
- 验证数据库连接字符串（用户名/密码/地址）
- 检查数据库防火墙规则

**场景3: Nginx反向代理超时**
- 增加proxy_timeout设置：
  ```nginx
  location /webuser/api/ {
      proxy_pass http://backend_server;
      proxy_read_timeout 300s;
      proxy_connect_timeout 75s;
  }
  ```

**场景4: 防火墙阻断内部通信**
- 检查iptables/firewalld规则
- 确保Web服务器可访问后端应用端口
